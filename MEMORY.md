# MEMORY.md — catatan kegagalan yang sudah diheal

Format: **symptom** → **root cause** → **invariant rule**.

- **[26-11-17 · core/db + core/log]**: `DB_Open` dan `fopen` selalu gagal walau file ada (bahkan dengan
  path absolut) → **Root cause**: di open.mp, `fopen()` dan `DB_Open()` di-sandbox ke folder
  `server/scriptfiles/`; path absolut di luar folder itu ditolak dan path relatif diresolusi
  *dari dalam* scriptfiles (jadi `"scriptfiles/rp.db"` menjadi `scriptfiles/scriptfiles/rp.db`) →
  **Invariant rule**: semua path file/database di kode Pawn relatif terhadap `scriptfiles/`
  (`"rp.db"`, `"server.log"`, `"settings.ini"`), dan server selalu dijalankan dengan cwd `server/`.

- **[26-11-17 · Pawn 3.10.11]**: `error 029: invalid expression, assumed zero` pada `case` /
  `return "teks"` → **Root cause**: Pawn tidak bisa `return "string literal"` dari fungsi non-array,
  dan `enum { A, B }` tanpa nama tidak dikompilasi oleh Pawn 3.10.11 → **Invariant rule**: string
  dikembalikan lewat buffer + `format()`, konstanta memakai `#define` bernilai polos (tanpa kurung)
  atau enum bernama, dan `case` hanya berisi konstanta polos.

- **[26-11-17 · core/callbacks]**: `public OnPlayerDialogResponse(...)` tidak pernah dipanggil →
  **Root cause**: nama callback dialog di open.mp adalah `OnDialogResponse`, bukan
  `OnPlayerDialogResponse` → **Invariant rule**: nama callback diverifikasi dari
  `server/qawno/include/` sebelum dipakai; jangan menebak.

- **[26-11-17 · build]**: pawncc keluar dengan exit code 0 meski ada error kompilasi →
  **Root cause**: pawncc lama selalu exit 0; kegagalan hanya terlihat di output →
  **Invariant rule**: `scripts/build.sh` menghitung baris `N Error(s)`/`N Warning(s)` di output dan
  exit non-zero; warning diperlakukan sama dengan error.

- **[26-11-17 · deployment]**: `systemctl start` pada omp-server langsung mati dengan
  `code=killed, signal=SYS` → **Root cause**: manager systemd menanamkan `SystemCallFilter=~`
  dan membatasi arsitektur syscall ke native x86-64, sementara `omp-server` adalah binary
  32-bit (i386); setiap syscall ia32 dibalas kill. Override di unit tidak menembus filter
  manager → **Invariant rule**: omp-server dijalankan lewat `scripts/supervise.sh`
  (loop restart + entri `@reboot` cron), bukan systemd.

- **[26-11-17 · deployment]**: server restart-loop dengan `Permission denied` pada
  `console.log` → **Root cause**: percobaan systemd sebelumnya membuat file itu sebagai
  root, sedangkan server jalan sebagai `boxd` → **Invariant rule**: seluruh isi
  `server/scriptfiles/` harus milik user yang menjalankan server (`chown -R boxd:boxd`),
  dan file log tidak boleh dibuat oleh proses root.

- **[26-11-18 · tunnel playit]**: client selalu "The server didn't respond" padahal dashboard
  playit menunjukkan download traffic masuk → **Root cause**: akun playit belum verifikasi email,
  sehingga playit mematikan tunnel berulang (`tunnel_count=1` → `0` tiap ~3 detik,
  `account_status=verified` ↔ `email_not_verified`); paket client berhenti di edge playit →
  **Invariant rule**: setelah claim agent, verifikasi email dulu; status sehat =
  `./scripts/tunnel-check.sh` MENJAWAB dan 10/10 percobaan UDP lolos.

- **[26-11-18 · scripts/status.sh]**: status tunnel terbaca "MATI" padahal tunnel aktif →
  **Root cause**: `sed -E 's/.*tunnel_count=([0-9]+).*/\1/'` bersifat greedy sehingga
  menangkap `pending_tunnel_count=0`, bukan `tunnel_count=1` → **Invariant rule**: ambil token
  pertama dengan `grep -oE '(^| )tunnel_count=[0-9]+'`, jangan pakai `.*` di depan pola.

- **[26-11-18 · core/db]**: login selalu "internal error" dan cek akun selalu -1 walau

  hanya valid untuk query ber-cache → **Invariant rule**: baca `DB_GetField*` langsung
